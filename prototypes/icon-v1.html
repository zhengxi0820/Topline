Topline 图标 · 四个方向（v1）

macOS Big Sur 风格圆角方形（824 画板）。核心意象：屏幕顶部一条逐字点亮的 KTV 歌词条。 每张卡下方附 64 / 32 / 16 px 缩小稿，用于检验 Finder / 关于窗口里的小尺寸可读性。
预览底色：

A · 顶部一条 推荐

夜色底上一条胶囊歌词条悬在画面上沿，左段是蓝紫 KTV 渐变、亮点停在演唱位置， 下方一条更暗的「下一行预告」。最直白地讲出产品名 Topline 的本义： 「顶部那行歌词」。剪影极简，16px 仍可辨认。

B · T 字进度 字母梗

紫罗兰渐变底上一个白色 T——横杠本身就是一条唱了一半的歌词条（实心白 = 已唱， 半透 = 未唱，端点带亮点），竖杠是 Topline 的 T。把「T = Topline」和「进度条」 合成一个字形，品牌感最强；小尺寸下 T 的识别度也好。

C · 逐字填充 最写实

直接把核心功能画出来：暗底上一行「Topline」，唱过的字亮白、未唱的字压暗， 游标处一道粉色光标停在字间，下面一行是暗淡的「下一行预告」。 信息量最足、最像产品截图；代价是 32px 以下文字糊掉，小尺寸只剩氛围。

D · 主旋律线 音乐术语向

取 Topline 的另一个词义「主旋律声部」：青蓝渐变底，一条白色旋律起伏线掠过 三条五线谱式的淡线。更「音乐 App」、更抽象，但和「屏幕顶部悬浮条」的产品 形态关联最弱，需要说明才看得懂。
