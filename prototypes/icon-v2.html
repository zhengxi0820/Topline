Topline 图标 · v2（C 逐字填充 × D 主旋律线 方向）

按「C 系 / D 系 / 两方向杂交」分三组，共 6 款。所有图标共用底部一份 SVG 定义， 每张卡下附 64 / 32 / 16 px 缩小稿。右上可切换预览底色。
预览底色：
杂交 · 形是 D，灵魂是 C

F1 · 旋律线逐字点亮 C×D · 推荐

把主旋律线本身当成歌词条：唱过的左段是青蓝渐变发亮，未唱的右段压暗， 白色亮点停在演唱位置。剪影是 D 的旋律线，细节是 C 的逐字点亮——两个喜欢的方向合在一颗图标里。

E1 · 歌词条里写字 A×C

A 的胶囊歌词条里真的装着一行「Topline」在逐字点亮：条内左段是蓝紫渐变、字全亮， 右段半透、字压暗。16px 下退化成 A 的极简剪影，放大后能读出字——远看近看都有内容。

C 系 · 逐字填充

E2 · 逐字 · 亮底 C 系

C 的构图搬到红粉渐变亮底：白字唱过的全亮、未唱的半透，白色游标带辉光。 在一堆深色图标的 Dock / 访达里最跳、最抓眼的一版。

E3 · 中文逐字 C 系

按产品真实场景画中文歌词「月亮代表我的心」：逐字硬切亮暗（第四个字后停一枚粉色游标）， 下方一条「下一行预告」。这是最「KTV」的一版——逐字而非逐笔，和实际填充行为一致。

D 系 · 主旋律线

F2 · 声波顶线 D 系

一排压暗的声波柱，一条亮渐变线把每个峰顶串起来——Topline = 波形顶上那条线。 概念最巧的一版：「顶部那条线」是画面的主角。左侧三个峰点是全亮的（已唱）。

F3 · 谱线上的音符 D×C

一条五线谱式的淡线上坐着一颗 ♫，音符本身在被「逐字点亮」：左半亮白、右半压暗， 粉色游标停在中间。图形元素最少的一版，靠填充和游标讲 KTV 的故事。
